Como usar este agente

Etapa 1 — Carregue os modelos: Adicione os PDFs de cartas anteriores já enviadas à ANTT. Quanto mais exemplos, melhor o padrão aprendido.
Etapa 2 — Carregue o ofício: Adicione o PDF do ofício recebido da ANTT que precisa ser respondido.
Etapa 3 — Preencha os dados: Informe número, data, responsável e o conteúdo da resposta a ser fornecida.
Etapa 4 — Copie o prompt: Use o botão "Abrir nova conversa" para levar o prompt gerado direto ao Claude com todos os arquivos.
Revisão e aprovação: O Claude entregará uma resposta quase pronta. Revise, ajuste e exporte o DOCX/PDF final.

Boas práticas recomendadas

· Sempre inclua pelo menos 3 cartas modelo para calibrar o padrão
· Mantenha uma pasta com os melhores exemplos por tipo de solicitação
· Revise sempre prazos legais e dados técnicos antes de assinar
· Para ofícios com questões jurídicas sensíveis, envolva o jurídico na revisão
· Salve os prompts gerados como template reutilizável por tipo de ofício
